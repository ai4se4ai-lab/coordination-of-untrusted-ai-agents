# Campaign protocol

protocol.yaml and case-study/document-service/scenarios/campaign.json were
specified before the first campaign execution. JSON syntax in YAML files avoids
an unnecessary YAML parser dependency. Models have an independent matrix.

Statuses and counts are distinct: model generated states include duplicates,
distinct states include the initial state; neither is an execution-trace count.
Scenario and trace counts refer to deterministic fixtures. Repeated runs are
reproducibility checks, not independent statistical samples. No speedup, token
cost, real-model quality or significance-test claim is made.

analysis.py preserves every case in each selected campaign and emits source-run
and hash pointers plus table-cell provenance. Failed development runs remain raw.

The manuscript results section contains four native PGFPlots/TikZ figures and 11 detailed result tables generated by paper_results.py. Run the analyze, claims and paper stages to regenerate them. detailed-results.json records source reports, trace-derived event partitions, shortest paths, intervention cuts and raw input hashes. The claim checker compares the entire generated TeX region with these data. Single-run timings are audit metadata; the descriptive plots do not treat deterministic fixtures or repeated development runs as statistical samples.
