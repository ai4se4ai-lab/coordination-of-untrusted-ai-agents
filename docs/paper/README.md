# Authoritative manuscript

main.tex contains all prose, mathematics, tables and native TikZ figures.
references.bib retains supplied citation keys. sn-jnl.cls and sn-mathphys-num.bst
are unmodified publisher template dependencies; download hashes are recorded.
verification/baseline contains historical copies and the recovered baseline PDF.

Use python scripts/reproduce.py analyze to refresh numerical marked regions, then
claims and paper. The final PDF is copied to dist/verified-coordination.pdf.
Do not edit generated table cells by hand or present finite checks as general
proofs. Author declarations remain unconfirmed until the author supplies facts.
