# Deviations and outstanding acceptance gates

* Keep docs/paper authoritative instead of moving the active user file to paper/.
* Absent historical explorers/reviews cannot be reproduced. Recovered publisher
  dependencies and all new model results have separate provenance.
* Formal modules cover the ranked protocol and separate restricted kernel/policy
  contracts. General normalization failure and joint publication constraints are
  currently exercised in Python scenarios, not fully connected in the proof model.
* Scoped TLAPS lemmas are separate from the still-open central inductive safety,
  history-budget and action-correspondence proof obligations (G4).
* Nine protocol mutation configurations do not complete the plan's whole mutation
  campaign. Identity-reuse and tentative-write faults have negative regression
  scenarios but no model-mutant counterexamples yet. Membership mutation is an
  abstract selected-context omission, not a general selector implementation proof.
* The case study covers lifecycle status plus typed interface/coverage metadata.
  It does not implement a production service, payload persistence or user roles.
* No real model backend or paid service was run. No model accuracy, latency,
  token-billing or speedup measurement is reported.
* Authorship is retained from the supplied manuscript; funding/competing-interest
  statements need author confirmation. Existing license is preserved.

These gaps do not reduce the requested acceptance criteria. Full plan completion
must not be claimed while they remain.
